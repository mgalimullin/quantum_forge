## Задание 3. Создание векторного индекса базы знаний
### логи создания базы

```
1. Загружаем документы
   Загружено документов: 31
2. Бьём на чанки
   Получено чанков: 814
3. Эмбеддинги
4. FAISS индекс
5. Сохранение индекса
---
ИТОГИ ПОСТРОЕНИЯ ИНДЕКСА
Чанков в индексе: 814
Время генерации: 5.16 секунд
```

### Используемая модель

В проекте для векторизации текстов применяется эмбеддинг-модель: sentence-transformers/all-MiniLM-L6-v2

### База знаний

Векторное хранилище: FAISS

Тип индекса: локальный FAISS-индекс

Индекс сохраняется на диск в директорию faiss_index.
