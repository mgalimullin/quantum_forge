### Почему не Qdrant на данном этапе

Qdrant является production-ready решением и лучше подходит для:

* распределённых систем,
* больших объёмов данных,
* онлайн-обновлений,
* REST/gRPC доступа.

Однако для текущей задачи:

* отсутствует необходимость в горизонтальном масштабировании,
* база знаний ограничена (~30 документов),
* вся система работает локально.

Использование Qdrant добавило бы инфраструктурную сложность без практической пользы для данного задания.

## Вывод

FAISS выбран как оптимальное решение для учебного RAG-пайплайна и прототипирования.

Qdrant рассматривается как целевая production-платформа при масштабировании системы.
